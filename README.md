# IoT Privacy Lab

가상 스마트홈 센서 데이터를 결합하면 생활 패턴을 추론할 수 있음을 보여주는 교육용 대시보드입니다. HTML, CSS, JavaScript만 사용하며 빌드 과정, 외부 라이브러리, 서버 통신이 없습니다.

## 프로젝트 구조

```text
.
├── index.html                    # 기본 주소에서 dashboard/로 연결
├── .nojekyll                     # GitHub Pages에서 정적 파일 그대로 제공
├── dashboard/
│   ├── index.html                # 화면 구조와 콘텐츠
│   └── assets/
│       ├── css/styles.css        # 스타일, 반응형 레이아웃, 애니메이션
│       └── js/app.js             # 가상 데이터, 상태, 화면 갱신, 이벤트 처리
└── README.md
```

기존 단일 HTML의 스타일과 스크립트를 분리했습니다. 자산 링크는 상대 경로를 사용하므로 GitHub Pages의 저장소 하위 경로에서도 동작합니다. 기존 `dashboard/` 경로도 유지합니다.

## 유지되는 기능

- 3일(72시간)의 가상 움직임·전력 데이터 수집
- 자동 재생·일시정지, 1시간 진행, 3단계 속도 조절
- 이벤트 수, 결합 레코드, 최근 8개 레코드와 최근 30개 로그 표시
- 24시간 수집 후 생활 패턴 추론 표시
- 72시간 히트맵, 초기화 및 다시 시연
- 반응형 레이아웃과 키보드 포커스 표시

모든 데이터는 브라우저 메모리에만 있으며 새로고침하면 초기화됩니다. 추론 결과는 실제 AI 분석이 아닌 가상 데이터 패턴에 맞춘 교육용 예시입니다.

## 로컬 실행

저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/` 또는 `http://localhost:8000/dashboard/`를 엽니다.

## GitHub Pages 배포

1. 변경 파일을 GitHub 저장소에 커밋하고 푸시합니다.
2. 저장소의 **Settings → Pages**에서 브랜치 기반 배포(**Deploy from a branch**)를 선택합니다.
3. 배포할 브랜치(예: `main`)와 루트 폴더(`/ (root)`)를 선택하고 저장합니다.
4. 배포가 완료되면 Pages에 표시된 주소로 접속합니다. 기본 주소는 `dashboard/`로 연결됩니다.

일반 프로젝트 저장소의 주소는 `https://<사용자명>.github.io/<저장소명>/` 형식입니다. 별도의 빌드 명령이나 GitHub Actions 워크플로는 필요하지 않습니다.

## 변경 후 확인

- 시작·일시정지·속도 변경과 1시간 진행이 정상 동작하는지 확인합니다.
- 23시간까지 추론 버튼이 비활성화되고 24시간부터 활성화되는지 확인합니다.
- 추론 표시 시 재생이 멈추고 결과가 표시되는지 확인합니다.
- 72시간에서 이벤트 144개, 레코드 72개가 표시되고 수집이 종료되는지 확인합니다.
- 초기화와 다시 시연으로 센서·표·히트맵·추론 결과가 초기 상태로 돌아가는지 확인합니다.
- 모바일 너비와 저장소 하위 경로에서 CSS·JavaScript가 정상 로드되는지 확인합니다.
